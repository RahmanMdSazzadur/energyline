# Fuse clearance envelope

Fuse_372_clearance_envelope.wrl is an original simplified dimension-based visualization, not manufacturer CAD. It models an 8.5 mm diameter cylinder, 8.0 mm body height, 0.5 mm mounting standoff and 0.6 mm leads spaced 5.08 mm apart. It omits molding details, markings, tolerances and lead-form variation. Lead extensions below the PCB are illustrative. KiCad VRML coordinates use 2.54 mm units.

Source: Littelfuse 372 datasheet, revision 2025-07-17, page 3: https://www.littelfuse.com/assetdocs/littelfuse-fuse-372-datasheet?assetguid=1a83e408-fdbe-48de-8389-c4f8ebb8232e

The model helps inspect placement. It is not proof of actual fit; compare purchased components and enclosure height before assembly.
