# Two-minute demo storyboard

0:00–0:15 — Define the inert mock module, five operations, assumed demand and 105-second takt.

0:15–0:30 — Explain S3's 150-second manual constraint and S2's next constraint. Distinguish the 165-unit ideal deterministic reference from stochastic/quality-loss experiments.

0:30–0:48 — Compare matched staffing with one and two actual manual S3 resources, then the faster S2/S3 candidate. A second fixture helps without meeting base demand.

0:48–1:05 — Play the recorded normal controller/equipment cycle: clamp, process, latch result, wait, transfer and exactly one completion.

1:05–1:30 — Play permit-loss fault, nonmoving reset acknowledgement, explicit recovery and quarantine. Do not call this real machinery safety or hardware commissioning.

1:30–1:48 — Compare three versus four production operators, both with paid rework staffing. Show output attainment, uncertainty and conversion-cost exclusions.

1:48–2:00 — State software scope, concept CAD, reproducibility and remaining empirical/hardware limits. The video is generated from actual software traces, not footage of physical equipment.
