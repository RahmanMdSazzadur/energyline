## KiCad

The board embeds standard KiCad footprint data. KiCad libraries use Creative Commons Attribution-ShareAlike 4.0 with the electronic-design exception described at https://www.kicad.org/libraries/license/. That exception permits electronic designs and generated files to use their own license; redistributing library collections is subject to the library license. This repository does not bundle the KiCad application or its complete footprint/3D-model libraries. Those are external dependencies of the optional KiCad container.

The small EnergyLine schematic symbol library and the fuse clearance envelope in `electrical/s3_interface/models/` are original project files. The fuse envelope is a simplified dimension-based visualization, not a manufacturer-supplied model.
